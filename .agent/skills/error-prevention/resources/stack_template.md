# Error Stack Entry Template

Use this format when adding a new entry to `stack.md`. 

```markdown
| Date | Issue | Cause | Prevention Rule |
| :--- | :--- | :--- | :--- |
| YYYY-MM-DD | [Brief description] | [Why it happened - max 1 sentence] | [New project rule to prevent this] |
```

## Rules for entries:
1. **Never Blame**: Focus on the technical cause, not the person/agent.
2. **Actionable Prevention**: The rule should be clear enough for an AI to follow (e.g., "Always use X", "Never do Y").
3. **Shortest Cause**: If it takes more than 10 words to explain the cause, simplify it.
